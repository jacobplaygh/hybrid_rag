## 🎯 What is Hybrid RAG?

Hybrid RAG (Retrieval-Augmented Generation) combines:
- **BM25 Keyword Search** - Fast, exact matching
- **Semantic Search** - Vector similarity matching
- **Hybrid Approach** - Best of both worlds

The system retrieves relevant documents and uses them to generate accurate answers.

## ✅ Prerequisites

- Python 3.10+
- Virtual environment (venv, conda, or similar)
- Basic command line knowledge
- NVIDIA API key (optional, for LLM features)
